# RMS metabolic transcriptomics

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.24012820.svg)](https://doi.org/10.5281/zenodo.24012820)

**Zenodo DOI:** [10.5281/zenodo.24012820](https://doi.org/10.5281/zenodo.24012820) — associated with the first archived GitHub release, [v0.1.0](https://github.com/cbuitrag24/RMS_Metabolic_Transcriptomics/releases/tag/v0.1.0). Subsequent changes on `main` are not automatically included in that archived release.

Research repository accompanying a manuscript on concordant metabolic transcriptomic alterations in rhabdomyosarcoma (RMS) compared with normal skeletal muscle.

The study analyses two public GEO datasets: [GSE108022](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE108022) (RNA sequencing; 64 RMS and 5 normal skeletal-muscle samples in the primary analysis) and [GSE28511](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE28511) (microarray; 18 RMS and 3 normal samples). It reports 13 concordantly enriched Hallmark gene sets, a shared set of 16 metabolic genes, and associations of a metabolic principal component with myogenic markers and CKM.

This repository preserves code, derived data and original statistical objects, but **does not yet demonstrate complete end-to-end reproduction from the public GEO inputs**. ## Historical RNA-seq workflow notes (preserved)

This directory contains R scripts supporting the differential expression analysis of GSE108022.

## RNA-seq analysis workflow

Run the scripts in the following order:

1. 14_preparar_diseno_DE.R
   Prepares sample metadata, platform assignments and the sample design table.

2. 15_preparar_counts_edgeR.R
   Constructs an unfiltered edgeR DGEList object from the original count matrix.

3. 22_preparar_analisis_primario_GPL16791.R
   Selects GPL16791 samples, filters low-expression genes and performs TMM normalisation.

4. 23_dispersion_QL_GPL16791.R
   Estimates dispersions and fits a robust quasi-likelihood model.

5. 24_DE_RMS_vs_Normal_GPL16791.R
   Performs the RMS-versus-normal differential expression test.

6. 26_corregir_tabla_DE_genes.R
   Generates the final differential expression tables while preserving gene identifiers and verifying statistical results.

## Important note

The definitive differential expression tables are those generated by script 26, with the suffix _CORREGIDO.

Script 24 is retained to document the original statistical workflow. Its preliminary CSV exports should not be used in place of the corrected tables.

## Data dependencies

The workflow requires the original GEO files GSE108022_counts_matrix.txt.gz, GSE108022_metadata.txt.gz and GSE108022_family.xml, as well as intermediate files generated by the preceding scripts.

The scripts currently use relative file paths and are intended to run from a common working directory containing their required inputs.

See the main repository README for the GEO accession and data source.

## Reproducibility status (2026-11-01)

The manuscript's 16-gene metabolic PCA (Figure 3) has been reproduced numerically and visually using a **documented reconstruction**, not the lost historical PCA script. The reconstruction is in [scripts/42_reconstruccion_PCA_metabolica_RMS_PENDIENTE_VALIDACION.R](scripts/42_reconstruccion_PCA_metabolica_RMS_PENDIENTE_VALIDACION.R). The filename is retained for continuity; validation results are recorded in [scripts/README.md](scripts/README.md).

**The entire manuscript is not yet reproducible end-to-end.** The 16-gene selection is now traceable to `data/Hallmark_leadingEdge_genes_compartidos.csv` and `scripts/43_verificar_seleccion_16_genes_metabolicos.R` (comparison with Table 2 verified; clean-environment execution not yet established). Scripts and/or provenance still need verification for myogenic-marker correlations, external differentiation score, Figure 4, Figure 5 regression and sensitivity analyses, and full raw-data-to-results execution. See [REPRODUCIBILITY_AUDIT.md](REPRODUCIBILITY_AUDIT.md) for the tracked inventory. Do not interpret script presence as proof of successful rerunning.

## Reproducing the 16-gene metabolic selection

From the repository root, with R installed, run:

```sh
Rscript scripts/43_verificar_seleccion_16_genes_metabolicos.R
```

Input: `data/Hallmark_leadingEdge_genes_compartidos.csv`, a derived output of script 25 based on the two original GEO enrichment analyses. Output: `seleccion_16_genes_metabolicos_verificada.csv` in the current working directory. The script compares the pathway intersection to the manuscript's Table 2 list and stops if they differ. The source CSV and the resulting 16-gene intersection have been inspected; no claim is made that the entire pipeline has been rerun in a clean environment.
