# Analysis scripts

This directory contains R scripts supporting the differential expression analysis of GSE108022.

## RNA-seq analysis workflow

Run the scripts in the following order:

1. 14_preparar_diseno_DE.R
   Prepares sample metadata, platform assignments and the sample design table.

2. 15_preparar_counts_edgeR.R
   Constructs an unfiltered edgeR DGEList object from the original count matrix.

3. 22_preparar_analisis_primario_GPL16791.R
   Selects GPL16791 samples, filters low-expression genes and performs TMM normalisation.

4. 23_dispersion_QL_GPL16791.R
   Estimates dispersions and fits a robust quasi-likelihood model.

5. 24_DE_RMS_vs_Normal_GPL16791.R
   Performs the RMS-versus-normal differential expression test.

6. 26_corregir_tabla_DE_genes.R
   Generates the final differential expression tables while preserving gene identifiers and verifying statistical results.

## Important note

The definitive differential expression tables are those generated by script 26, with the suffix _CORREGIDO.

Script 24 is retained to document the original statistical workflow. Its preliminary CSV exports should not be used in place of the corrected tables.

## Data dependencies

The workflow requires the original GEO files GSE108022_counts_matrix.txt.gz, GSE108022_metadata.txt.gz and GSE108022_family.xml, as well as intermediate files generated by the preceding scripts.

The scripts currently use relative file paths and are intended to run from a common working directory containing their required inputs.

See the main repository README for the GEO accession and data source.
