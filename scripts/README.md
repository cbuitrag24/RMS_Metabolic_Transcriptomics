## Figure 3: 16-gene metabolic PCA

`scripts/42_reconstruccion_PCA_metabolica_RMS_PENDIENTE_VALIDACION.R` is a **documented reconstruction, not the original historical PCA script**. Its historical filename retains `PENDIENTE_VALIDACION`, but the investigator has since executed it successfully and compared the reconstructed PDF with the original Figure 3.

Required files in the R working directory:

- `GSE108022_GPL16791_filtrado_TMM.rds`, generated by script 22.
- `GPL16791_diseno_muestras.csv`, generated by script 22.

Run from the directory containing those inputs:

```powershell
Rscript "42_reconstruccion_PCA_metabolica_RMS_PENDIENTE_VALIDACION.R"
```

If the script is kept inside `scripts/` while inputs are at the repository root, invoke `Rscript "scripts/42_reconstruccion_PCA_metabolica_RMS_PENDIENTE_VALIDACION.R"` from the repository root instead.

The reconstruction uses the original gene-symbol annotation `dge$genes$gene` rather than the numeric row names of `dge$counts`. It extracts the 16 specified metabolic genes and 64 RMS samples, calculates TMM-normalised log2 CPM with `prior.count = 2`, and applies `prcomp(t(matriz), center=TRUE, scale.=TRUE)`.

Reported successful local verification:

- Exactly 16 genes, each uniquely mapped; 64 RMS tumours and five normal samples in the starting DGE.
- PC1: **36.481659%** (original Figure 3: 36.48%).
- PC2: **13.131902%** (original Figure 3: 13.13%).
- All 16 PC1 loadings negative.
- Reconstructed PDF `Figura_3_PCA_Metabolico_RMS_RECONSTRUCCION.pdf` visually matches the original `Figura_3_PCA_Metabolico_RMS_publicacion.pdf`.

The original PDF is not overwritten. These checks establish numerical and visual agreement for Figure 3, **not full end-to-end reproducibility of the manuscript**.
